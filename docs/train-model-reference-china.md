# 中国车型的实车建模参考

核对日期：2026-10-29。参考原型固定为标准银蓝 CRH380A、标准银红 CR400AF；不混用 CRH380AL、港铁动感号、CR400AF-Z / S 的涂装与头型。

## CRH380A

- [中车四方产品介绍与实车图集](https://www.crrcgc.cc/sfgf/2013-12/05/article_6DE3945F7E2B4887A2D46B0618286261.html)：已在浏览器实际查看第一张高架上的俯视斜前照片；用于核对鼻锥、窗带和车顶。页面其余图主要是内饰，未作为车体外形证据。
- [同页外观原图](https://www.crrcgc.cc/sfgf/2013-12/05/67313/2025072814485238199.png)。实车：银白上部、连续深色侧窗带、窗带下细蓝线、向车鼻方向收尖的深色区域；风挡是向前下方倾斜的弧面，中央有分隔；鼻尖较圆且有车钩舱盖接缝。
- [中车英文规格页](https://www.crrcgc.cc/en/2016-02/29/article_23B271155942426F9EEC7A23DF4DBD91.html)：头车 26,500 mm、中间车 25,000 mm、宽 3,380 mm、高 3,700 mm。中文页核对 8 辆、全长 203 m。英文页本轮正文抓取超时，尺寸由搜索索引读取。
- [港铁 CRH380A 技术资料](https://www.mtr.com.hk/archive/corporate/en/press_release/PR-16-083-E.pdf)：搜索索引给出相同尺寸，打开时维护中；仅作尺寸旁证，不采用该版本橙色涂装。

- [中车标准型产品介绍](https://www.crrcgc.cc/sfgf/2015-11/04/article_E7691BD1DADD4C799E29B682C86DADD3.html)：8 辆、整列 208.95 m、宽 3,360 mm。
- [中车非智能型介绍与图集](https://www.crrcgc.cc/crrcgc/2026-05/09/article_2026050917102785945.html)。已在浏览器实际查看第一张低角度侧前照片。
- [已核对的外观原图](https://www.crrcgc.cc/crrcgc/2026-05/09/bc6b1b22e39f42e498e5809a1b71b42d/2026050917093143190.png)：深色前风挡下倾，旁边有独立梯形驾驶室侧窗；银灰底色、侧窗带下红线、车头侧面红色宽楔形包围深色区域；鼻尖为有舱盖接缝的圆钝轮廓；底裙部分遮挡转向架。
- 同页另外两幅图已定位但工具获取失败，**不计作已视觉检查的照片**。

## 尺寸与模型边界

CR400AF 用头车 27.525 m、中间车 25.65 m 作为外观建模参考，组合总长与中车 208.95 m 一致；官网本轮未直接提供每种车的完整尺寸图，不能把这些单车参数写成已逐项核验的厂家 CAD 尺寸。原型长、车体长、车钩中心距也不是同一个口径。

这次模型以外形相似度为目标：分别拟合侧视/俯视轮廓，驾驶室玻璃与侧窗沿车体曲面贴合，门窗采用分组排布，头车和中间车长度不同。车底小设备、舱盖分缝和自由车厢数属于可视化近似，不声称是生产工程模型。

官方照片仅供人工观察；不作为网页贴图、不打包第三方照片或下载模型文件。网站用本项目原创建模生成的预览图。
